Flask Educational App

This page is rendered by Flask using Jinja2 — a templating engine that processes HTML files before sending them to the browser.

How Templates Work

Flask looks for templates in the templates/ folder next to your app. render_template("index.html") reads this file, processes any Jinja2 syntax (like {{ variable }} or {% for %}), and returns the resulting HTML string as the response body.

Available Endpoints

GET  /                    → This page (HTML)
GET  /users               → List all users (JSON)
GET  /users?role=admin    → Filter users by role (JSON)
GET  /users/1             → Get user by ID (JSON)
POST /users               → Create user (JSON body: {"name": "...", "role": "..."})
POST /echo                → Echo everything Flask parsed from the request

Try it with curl

# Get all users
curl http://localhost:5000/users

# Get one user
curl http://localhost:5000/users/1

# Create a user
curl -X POST http://localhost:5000/users \
     -H "Content-Type: application/json" \
     -d '{"name": "Dave", "role": "student"}'

# Echo your request back
curl -X POST http://localhost:5000/echo \
     -H "Content-Type: application/json" \
     -d '{"hello": "world"}' \
     "http://localhost:5000/echo?debug=true"
